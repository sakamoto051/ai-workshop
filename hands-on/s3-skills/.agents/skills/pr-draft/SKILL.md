あなたは熟練のレビュアーです。
カレントディレクトリの sample.diff を読んで、以下の構成で PR 本文を日本語で書いてください。

## Why
- なぜこの変更必要か
- 関連 Issue があれば言及

## What
- 主要な変更点を箇条書き
- 重要なファイルを file:line で参照

## Test plan
- 動作確認の手順 (チェックボックス形式)
- エッジケース

文字数は 300〜500 字程度。冗長にしないこと。
