# Session 3 デモンストレーション

このディレクトリは、ワークショップ中の「デモンストレーション（Before & After）」スライドに合わせて、実際にAIエージェントの挙動の違いを実演するためのものです。

**「AIへの依頼文（プロンプト）は全く同じなのに、プロジェクトにSkillが設定されているか否かで、生成されるコードの品質が劇的に変わる」** ことを実演できます。

## ディレクトリ構成
- `project-without-skill/`：スキルが全く設定されていない、素のプロジェクト
- `project-with-skill/`：`.agents/skills/backend/SKILL.md` が配置されたプロジェクト

## 実演手順

プレゼンターは、それぞれのディレクトリに移動し、中にある `run.sh` を実行して比較を見せてください。

### 1. 【Before】スキルなしプロジェクト
```bash
cd project-without-skill
./run.sh
```
➡ AIは「とりあえず動く」ものの、コントローラーにDB操作などがベタ書きされた平凡なコード（`expected/` 内のサンプルのような内容）を生成します。

### 2. 【After】スキルありプロジェクト
```bash
cd ../project-with-skill
./run.sh
```
➡ 実行しているコマンドは【Before】と全く同じですが、AIが自動的にローカルの `backend` スキル（遅延読み込み）をフックし、ドメイン分離・Result型を用いたエンタープライズ品質のコード（`expected/` 内のサンプルのような内容）を生成します。

## 注意事項
- 万が一、デモ中のネットワークトラブル等で生成が遅れたり失敗した場合の**バックアップ（期待される完成形のモック）**として、それぞれのプロジェクト内の `expected/` ディレクトリにあらかじめサンプルコードを用意しています。実演が難しい場合はこちらのコードを見せて比較してください。
