# 社内TypeScriptコーディング規約

当社のTypeScriptプロジェクトにおいて、型安全性を最大限に担保するため、以下の規約を厳守してください。

## 第1条：any 型の完全禁止
- いかなる理由があっても `any` 型の使用は禁止します。
- 外部APIや動的なデータを扱う場合は、`unknown` 型を使用し、必ずZod等のバリデーションライブラリを用いて型推論（Type Guard）を行ってください。

## 第2条：返り値の型定義の義務
- すべての関数およびクラスメソッドには、必ず明示的な返り値の型（Return Type）を定義してください。
- データベースから取得した結果をそのまま返すのではなく、必ず対応する Entity または DTO のインターフェース/クラスの配列（例: `Promise<UserDto[]>`）として型付けして返却してください。
