# AI Feedback Inbox

AIの操作や出力に関するユーザーからの指摘事項を一時的に保管するファイル。
ここに蓄積された指摘は定期的に見直され、汎用的なルールとして `AGENTS.md` や `DESIGN_RULES.md` に昇華される。

## 2026-07-08
