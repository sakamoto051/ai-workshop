# Agent Skills (スキル)

## 📝 概要
Agent Skills とは、エージェントに対して**特定のワークフローやタスクの処理手順を教え込む、再利用可能なプロンプト/命令パッケージ**です。

単なる「指示のテンプレート」とは異なり、メタデータ（frontmatter）を持つことで、エージェントがユーザーの依頼意図から自動的にそのスキルを検知・適用する仕組み（セマンティックマッチ）を備えています。

## ⚙️ スキルの定義形式 (`SKILL.md`)
プロジェクト固有のスキルは、`.agents/skills/<skill_name>/SKILL.md` に配置します。ファイルは **YAML frontmatter** と **Markdown の本文** で構成されます。

```markdown
---
name: pr-draft
description: ステージング差分または与えられた diff から PR 本文の下書きを生成
---
あなたは熟練のレビュアーです。
カレントディレクトリの staged diff を確認し、以下の構成で PR 本文を日本語で記述してください。

## Why
- なぜこの変更が必要か
## What
- 主要な変更点
## Test plan
- 動作確認の手順
```

*   **name**: スラッシュコマンドとして手動で呼び出す際の名前（例: `/pr-draft`）。
*   **description**: エージェントがセマンティックマッチで使用する説明。ユーザーの依頼（「PRの下書きを作って」など）と一致すると自動でこのスキルがロードされます。
*   **Body (Markdown)**: ロードされた後にエージェントのシステムプロンプトにインジェクションされる具体的な指示。

## 🚀 起動方法の種類
1. **手動起動 (Slash Command)**: CLI で `/pr-draft` のように明示的にコマンドとして実行します。
2. **自動起動 (Trigger-Matched)**: 自然言語で「PRの下書きを作って」と指示すると、エージェントが description メタデータを走査し、セマンティック一致したスキルを自動的にロードします。
