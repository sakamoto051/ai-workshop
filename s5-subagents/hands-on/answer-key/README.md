# answer-key

ハンズオン#1・#2 で作成する Subagent 定義の答え合わせ用ファイル。

`.agents/agents/` には配置していない（自動的に読み込まれると、学習者が自分で定義を書く体験がなくなるため）。詰まったグループや時間短縮したい場合は、該当ファイルを `.agents/agents/` にコピーして進める。

```bash
# コピー用コマンド例
cp answer-key/reviewer.md .agents/agents/
cp answer-key/frontend-researcher.md .agents/agents/
cp answer-key/backend-researcher.md .agents/agents/

# シンプルなエージェントは配置するだけで自動認識されます（インストールや再起動は不要です）
```
